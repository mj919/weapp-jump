### 3、H5 网页版

项目附带了一层 H5 适配（`h5-adapter.js`、`index.html`、`server.js`），不装微信开发者工具也能在浏览器里玩：

```bash
node server.js 8000
```

- 本机访问 `http://localhost:8000/`
- 同一 Wi-Fi 下其他设备访问 `http://<本机局域网IP>:8000/`（启动时会打印）
- 必须通过 HTTP 访问，直接双击 `index.html` 无法加载贴图

说明：`game.js` 原文件未作修改。排行榜、分享、对战等依赖微信服务端的功能在 H5 下不可用，单机玩法完整；手机端触摸操作，桌面端按住鼠标左键蓄力。

### 4、更换人物照片

页面右上角「换形象」可以上传自己的照片替换跳跃小人：

- 支持 PNG 透明底直接抠图；普通照片可勾选「自动去除纯色背景」，复杂背景会自动退化为圆角照片贴纸
- 照片会跟随原有的跳跃、蓄力压扁、落地、摔倒动画
- 照片只保存在浏览器 `localStorage`，不会上传到任何服务器；「恢复原形象」可还原
- 默认形象来自 `res/avatar-user.png`（透明底 PNG），换默认图直接替换这个文件即可；右上角上传的照片只影响当前浏览器
- 本浏览器点过「恢复原形象」后会记录偏好，默认图不会再次自动覆盖
